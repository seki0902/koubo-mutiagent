# 爆文结构模板

## 一、钩子库（5 种）

每种钩子给出句式模板 + 可选词库。创作时从词库中自由组合，不写死任何一个词。

### 1. 反常识打破
- **句式**："[一个普遍认知]？[打破词]……[反转结论]。"
- **打破词可选**: 其实 / 醒醒吧 / 大错特错 / 根本不是 / 别再 / 别高兴太早 / 颠覆你的认知
- **变体**: "很多家长还不知道，现在最缺留学生的根本不是[X]，而是[Y]。"
- **原文实例**:
  - "留学回来就去卷大厂？醒醒吧！那是孩子回国后最亏的选择。"
  - "QS前100回国最好的结局是考公吗？其实根本就不是。"
- **新增变体**:
  - "好多QS前一百的海归都走偏了，拼命挤[X]和[Y]。"（路径否定式——不是认知错，是方向错了）
  - "央国企绝对不会希望你知道的这[X]条求职捷径。"（秘闻揭露式——暗示被藏起来的捷径）
  - "X%的留学生回国都在挤[大厂名]的独木桥，但我真心提醒一句……"（窄桥隐喻式——先描绘拥挤的主流赛道）
- **何时用**: 纠正一个常见误解

### 2. 政策红利
- **句式**："[权威信号] + 留学生[获益点]。"
- **信号词可选**: 刚刚定音 / 释放了信号 / 明确表态 / 官宣
- **获益词可选**: 含金量暴涨 / 利好来了 / 绿色通道全面开放 / 人才引进升级
- **原文实例**:
  - "上面释放了一个海归利好信号，99%的留学生家长还在蒙在鼓里。"
  - "人民日报刚刚定音，留学生被国家正式纳入重点人才。"
- **新增变体**:
  - "留学生的铁饭碗要变成金饭碗了。前段时间，[权威机构/部门]新成立了[X]……"（升级隐喻式——不仅稳，还要更值钱，先抛结论再引权威）
- **何时用**: 有新的政策/官方信号要解读

### 3. 恐吓焦虑
- **句式**："[负面后果]，[比例]的[X]还不知道/漏掉了[关键动作]。"
- **后果词可选**: 卡审核 / 白交了 / 错过窗口期 / 简历白投了 / 直接被筛掉
- **比例词可选**: 九成 / 95% / 99% / 绝大多数 / 大部分 / 没几个家长知道
- **原文实例**:
  - "停，别高兴得太早，90%的海归都会漏掉留学人事档案建档。"
  - "太可惜了，国家专为留学生设了通道，年年招不满，知道的家长寥寥无几。"
- **何时用**: 警告被忽视的风险或遗漏
- **新增变体**:
  - "留学生今年秋招可能是最容易的一年了，这几个[X]开始集中发力送offer了。"（希望反转变体——不说难，说容易，制造稀缺紧迫）
  - "现在留学生要自己找工作的都是大傻子，因为有个[X]能让孩子人在海外就提前被锁定。"（极端攻击式慎用，攻击性极强，适合强人设账号）

### 4. 身份唤醒
- **句式**："所有[X]听好/注意了……"
- **唤醒词可选**: 听好 / 注意了 / 下面这段话可能颠覆你的认知 / 看过来
- **变体**:
  - "很多家长还不知道……"
  - "家有XX届留学生的注意了！"
  - "想去XX的留学生注意了"
  - **叠加式**：身份唤醒 + 政策红利双钩叠用——先喊话人群，再跟权威信号（"留学生家长注意，上面对海归就业发展重新定调"），全程正向权威起手
- **原文实例**:
  - "所有留学生家长听好，下面这段话可能颠覆你的认知。"
  - "家有二四至二七届留学生的注意了！"
  - "留学生家长注意，上面对海归就业发展重新定调，重点保障海归人才就业发展。"
- **何时用**: 直接喊话特定人群；叠加式用于有政策背书的平台/渠道推介
- **新增变体**:
  - "QS前100的留学生重磅好消息来了！[企业名]开始引进海外留学生……"（纯正向爆炸式——不制造焦虑不抛问题，直接宣告好消息）
  - "恭喜留学生！这次有福了！[企业名]就在最近……"（祝贺式唤醒——比"注意了"更亲近更兴奋）

### 5. 时效捡漏（招聘会专用）
- **句式**："[XX届]留学生注意了/快来捡漏！[活动名称]。[核心卖点]。"
- **活动类型可选**: 招聘会 / 双选会 / 人才对接会 / 人才对接活动 / 高端人才活动 / 引才项目 / 线上双选会 / 专场 / 捡漏场 / 重磅来袭
- **卖点词可选**: QS前XX优先 / 海归专属 / 岗位匹配度更高 / 跳过网申 / 免笔试 / 定向岗位
- **原文实例**:
  - "各位海归留学生和留学生家长们注意了，7月份这三个刚刚官宣的、专门给留学生的捡漏机会，一定得盯住了！"
  - "杭州专属海归人才招聘会，重磅来袭！留学生身份就是你的专属入场券。"
  - "想去上海的留学生注意，这场双选会真的值得提前关注。"
- **何时用**: 通报招聘会/双选会/对接会等时效性活动
- **新增变体**:
  - "X月！留学生机遇拉满！[组织/机构]开放了超[X]个稀缺席位……"（满额红利式——强调机会爆发，不是捡漏是收割）

## 二、结构骨架（4 套）

### A1: 通用列举式
适用: 红利/赛道/网站/攻略等有多个独立要点的主题

| 段位 | 做什么 | 字数 |
|---|---|---|
| Hook | 选一种钩子，一句话撕开 | 15-30 字 |
| 第一条 | 列出第一条信息/策略 | 40-65 字 |
| 第二条 | 列出第二条信息/策略 | 40-65 字 |
| 第三条 | 列出第三条信息/策略（可选） | 35-55 字 |
| 锚定 | 价值总结 + 紧迫感 + 与国内生对比 | 30-50 字 |
| CTA | 评论区互动 | 15-25 字 |

> 合计：175-290 字（不含第三条：140-235 字，此时加长锚定或合并段来补足）

### A2: 通用说教式
适用: 实操误区/认知纠正/单赛道深挖（如外企/欧企/某行业）

| 段位 | 做什么 | 字数 |
|---|---|---|
| Hook | 选一种钩子，一句话撕开 | 15-25 字 |
| 场景展开 | 描绘现状/问题，建立共鸣 | 45-70 字 |
| 核心论述 | 给出答案/方案，连续推进不列举 | 70-120 字 |
| 锚定 | 价值总结 + 紧迫感 + 与国内生对比 | 35-55 字 |
| CTA | 评论区互动 | 15-25 字 |

> 合计：180-295 字

### B: 招聘会
适用: 招聘会/双选会/对接会/引才项目等时效性活动

| 段位 | 做什么 | 字数 |
|---|---|---|
| Hook | 时效提醒 + 活动名称 + 核心卖点 | 20-30 字 |
| 信息 | 时间、地点、企业、岗位方向 | 60-90 字 |
| 参与方式 | 面向谁、怎么参与、为什么值得去 | 50-75 字 |
| 紧迫 | 报名热度/截止时间/席位有限 | 35-60 字 |
| CTA | 评论区互动（扣关键词发报名入口+清单） | 15-25 字 |

> 合计：180-280 字

### B2: 单企业/单组织直招
适用: 单一企业或组织（如福耀、字节、联合国）的招聘通告，非多企业招聘会

| 段位 | 做什么 | 字数 |
|---|---|---|
| Hook | 正向宣告好消息 + 企业/组织名 + 核心卖点 | 20-30 字 |
| 人群+待遇 | 面向哪届、入职待遇、福利亮点（年薪/安家费/假期等数字锚定） | 55-85 字 |
| 岗位分布 | 工作地点、岗位类型、专业方向 | 35-55 字 |
| 优势强化 | 为什么留学生占优 + 与国内生对比 | 30-50 字 |
| CTA | 评论区互动（扣关键词发投递入口+岗位清单） | 15-25 字 |

> 合计：155-245 字。注意：单企业招聘稿比B更短，聚焦一家，不要铺陈。待遇数字必须实时搜索确认。

## 三、CTA 模板

统一模式：关键词 + 悠悠老师 + 具体交付物。

> "评论区扣「[关键词]」，悠悠老师[交付词][具体发什么]。"

**引导词可选**: 扣（首选）/ 敲 / 打 / 留
**交付词可选**: 立马发给您 / 同步给您 / 逐一发 / 全部打包好啦 / 发你（备选）
**交付物必须明说**:
- 招聘会 → "报名入口和岗位汇总"
- 赛道红利 → "官方申请入口和匹配建议"
- 平台盘点 → "平台入口和岗位清单"
- 实操攻略 → "简历模板"或"完整流程清单"
- ❌ 禁止只说"帮你看看""帮你分析"不跟交付物

**关键词规律**:
- 招聘会类: 城市名（杭州/上海/深圳/广东/北京）
- 赛道类: 主题词缩写（小众/三三）
- 数字简化: 一 / 1 / 11
- 通用互动: 海归 / 求职 / 职业规划 / 建档 / 报名

**变体**:
- "有需要的家长啊，评论区扣「XX」，悠悠老师同步给您。"
- "想知道怎么参加的，扣「XX」，悠悠老师立马发给您。"
- "扣「XX」，悠悠老师逐一发。"

**扩展模式（来自爆文原文）**:

| 模式 | 句式模板 | 适用场景 |
|------|---------|---------|
| 方括号数字型 | `敲[1]` / `[88]同步[交付物]` | 极简互动，降低输入成本 |
| 信息收集型 | `留言院校+专业，悠悠老师帮孩子精准分析` | 获取用户画像，用于后续私域转化 |
| 三字明确关键词 | `评论区留下"央国企"三个字，悠悠老师直接发你` | 清楚告知该敲什么，降低犹豫 |
| 打+缩写 | `下方打欧企，悠悠老师把[交付物]发给你` | 行业缩写作关键词，精准圈人 |
| 关注型 | `关注悠悠老师，带你拿下更多名企offer` | 涨粉导向（慎用，可能与交付承诺冲突） |

**交付物话术更新**:
- 单企业招聘 → "投递入口和岗位清单"
- 国际组织 → "投递通道和岗位匹配表"
- 欧企/赛道 → "在华XX企业清单和投递入口"
- 平台盘点 → "平台入口和岗位清单"（不变）

## 四、人称规则

- **自称**: 悠悠老师（不用"我"）
- **对象**: 家长、留学生家长（对家长说话时，留学生 = "孩子"）
- **届数写法**: 支持两种 — "26届"（数字）或"二六届"（汉字），保持一致即可

## 五、写作规范细则

> 以下规范对应 SKILL.md Step 6 自检项，创作时逐条参照。每一项给出 ❌ 错误写法和 ✅ 正确写法。

### 1. 去书面腔（对应自检 #7）

❌ "深圳人社局" → ✅ "深圳官方"
❌ "大量岗位明确标注海归优先" → ✅ "好多岗位点名要留学生"、"偏爱 QS 前 100 的海归"
❌ "参考往年情况" → ✅ 直接说事，不加帽子
❌ "经持续 31 天" → ✅ 直接说时间
✅ 降低门槛型过渡："不管读的什么专业都可以……"——用于平台/渠道类，缓解家长焦虑、扩大覆盖面

### 2. 去废话（对应自检 #3）

❌ "临近才看根本来不及" → ✅ "席位有限，现在就得准备"
❌ 书面自问自答（"线下双选会的含金量在哪？"）→ ✅ 删掉，直接说结论
✅ 呼吸用设问（"开放地点呢？在杭州大会展中心。""怎么参加呢？微信搜粤就业小程序。"）→ 保留，这是口播剥洋葱的气口，自问自答是为了把一个信息拆成两口呼吸

### 3. 对比精炼（对应自检 #10）

❌ 成段对比："普通孩子还在招聘软件上焦虑刷新，你家孩子已经绕过海选、直通面试了。"
✅ 一句嵌在信息里："这些岗位国内生连投递资格都没有"

### 4. 企业名真实 + 轮换（对应自检 #8、#11）

必须实时搜索确认企业有海外业务，从第六章轮换池取，每次换一批。

### 5. 装逼有度（对应自检 #4、#9）

✅ 家长能懂的装逼词：降维打击 / 专属通道 / 金饭碗 / 铁饭碗 / 信息差 / 绿色通道
❌ 家长听不懂的互联网黑话：卡位 / 闭环 / 赋能 / 颗粒度 / 底层逻辑

### 6. 不瞎承诺（对应自检 #6）

❌ "参会企业完整名单" → ✅ "岗位汇总" 或 "报名入口 + 配套资料"
❌ 承诺发"完整XX"但不确定有没有 → ✅ 说"配套资料""整理好的XX"

### 7. 单句精炼 + 洋葱剥层（对应自检 #7）

单句 ≤ 25 字。不用破折号、分号、省略号。口语稿就是短句连发。

**洋葱法则**：一个呼吸单元只给一个信息点。不要一句话塞 4 个信息。

❌ "「京彩就业」北京秋招首场双选会9月15号正式定档，面向2027届本硕博毕业生，免海投直接跟HR面对面。"
→ 一口气塞了 活动名 + 时间 + 人群 + 好处，家长听完只记得"有个会"

✅ 拆成四层：
- "「京彩就业」——北京秋招首场双选会，9月15号，正式定档啦。"（活动+时间）
- "面向2027届本硕博毕业生。"（人群）
- "免海投，直接跟HR面对面。"（好处）
- "刷到视频的家长啊，一定要转发给孩子看一看。"（行动）

### 比例词轮换

每次创作从以下随机取，不要总用"90%"：
> 九成 / 95% / 99% / 绝大多数 / 大部分 / 没几个家长知道

## 七、口播呼吸与节奏规范

> 核心原则：**爆文不写文章，爆文是"说话"。** 口播稿的唯一标准不是信息量——是家长听完能不能一口气记住三个关键词。以下六条法则决定稿子是"念稿"还是"唠嗑"。

### 1. 气口词法则

每个句号前尽量落在一个虚词上。这不是废话，是口播的**呼吸标记**。没有气口词 = 念稿；有气口词 = 说话。

**气口词库**：
| 词 | 用途 | 例句 |
|-----|------|------|
| 啊 | 陈述收尾、喊话 | "刷到的家长一定要转发给孩子看一看啊。""这些岗啊，就是为留学生量身定做的。" |
| 呢 | 设问、对比标记 | "国内生呢？连投递资格都没有。""开放地点呢？在XX。" |
| 嘛 | 理所当然 | "信息差呢，就是机会差嘛。" |
| 啦 | 轻松宣告 | "全部打包好啦。""正式定档啦。" |
| 呀 | 强调、感叹 | "18到30岁硕博留学生呀，适配度最高。" |
| 吧 | 祈使、劝告 | "赶紧转发给孩子看一看吧。" |

**强制规则**：
- 钩子段至少 1 个气口词
- 信息段每 2 句至少 1 个气口词
- CTA 段必须以气口词收尾（啦/呀/啊）

### 2. 洋葱剥层法则

**一个呼吸单元只给一个信息点。** 一段里每句一层，用过渡词做层间标记，像剥洋葱一样一层一层揭开。

**层间过渡词**：
| 过渡词 | 作用 | 例句 |
|--------|------|------|
| 那 / 那这个呢 | 引出下一层 | "那这场呢，不是普通综合场啊。" |
| 我跟你说啊 | 强调重点 | "我跟你说啊，留学生投国际组织简直是天生一对。" |
| 听好了 | 敲黑板 | "听好了：Z开头是什么？总部岗，神仙打架。" |
| 最有价值的地方在哪呢？ | 设问引路 | "最有价值的地方在哪呢？大量涉外岗点名要留学生。" |
| 为什么啊？ | 设问引路 | "为什么啊？国际组织工作语言就是英语。" |
| 怎么参加呢？ | 实操指引 | "怎么参加呢？线上加线下同步开放。" |
| 说真的啊 | 掏心窝子 | "说真的啊，留学生投国际组织简直是天生一对。" |

**禁止**：一句话塞 4 个信息点的"压缩饼干句"。

### 3. 信息砸脸法则

不要解释，只砸结论。不做因果推理，直接给事实。

❌ "最大的好处是跳过网申，直接跟HR面对面，流程快、筛选松。"
→ 在解释为什么好

✅ "免网申，直接跟HR当面聊。"
→ 只给事实

**数字轰炸模式**：3-4 个数字连续砸，中间不加过渡词。
> "入职年薪80~150万。一次性安家费30万。带薪年假25天。留学生录取率高达70%。"

数字之间用句号，不用逗号——每个数字单独一口呼吸。

**社交证明**：身体里至少埋 1 处"往届验证"，给家长吃定心丸。
> "往届有大量海归通过这场招聘会现场拿下满意offer。"
> "去年一场类似活动，大批海归现场就拿了面试，今年只会更多。"

### 4. 临场感词库

从"编辑稿"切换到"聊天稿"，关键在于用**短视频评论区的话**，不用**公文的话**。

| 书面/工整 | → | 口播临场 | 原理 |
|-----------|-----|---------|------|
| 敲 | → | 扣 | 更像刷视频时随手打的字 |
| 发你 | → | 立马发给您 / 逐一发 | "立马"有即时满足感 |
| 打包好了 | → | 全部打包好啦 | "啦"消解工整感 |
| 需要的 | → | 有需要的家长啊 | 加称呼+气口，有筛选感 |
| 评论区打XX | → | 评论区扣「XX」 | 扣比打更轻、更像短视频 |
| 同步一下 | → | 同步给您 | 加"您"有专家施舍感 |

### 5. 精英泄密姿态

人设不是"友好顾问"，是**泄露行业秘密的精英知情者**。每段的底层情绪是"我告诉你一个你不知道的事，信不信随你"。

**CTA 姿态**：
- ❌ 客服式："需要的敲XX，我发您。"
- ✅ 施舍式："有需要的家长啊，评论区扣「XX」，悠悠老师同步给您。"
  - `有需要的` = 筛选，不是我求你要
  - `同步给您` = 东西我已经准备好了，你开口就给

**对比姿态**：
- ❌ 解释式："国内生语言和跨文化这块根本补不上，所以这些岗位留学生优势很大。"
- ✅ 否定式："国内生呢？连投递资格都没有。"
  - 一句否定，不解释为什么
  - 用 `呢？` 设问制造停顿，停顿之后直接砸否定结论

### 6. 口播自检清单

写完后朗读一遍，逐项验证：

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 气口覆盖率 | 每两句至少一个气口词（啊呢嘛啦呀吧） |
| 2 | 洋葱完整度 | 每句只给一个信息点，无"压缩饼干句" |
| 3 | 数字链 | 关键信息有 3+ 数字连续轰炸 |
| 4 | 社交证明 | 身体里至少埋了 1 处往届验证 |
| 5 | 临场词 | 用了 扣/立马/全部打包好啦 而非 敲/发你/打包好了 |
| 6 | 施舍感 | CTA 包含"有需要的"+气口词收尾 |
| 7 | 对比刺感 | 国内生对比 ≤ 一句半，绝对否定，不解释 |
| 8 | 朗读测试 | 读出来不喘不过气、不卡壳、像在跟人唠嗑 |
