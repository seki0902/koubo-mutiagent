# 留学生求职赛道黑话词库

创作时从各类别中选取词汇注入口播稿。每版至少 5-8 个。

## 一、身份锚点词

- **人群标签**: 海归、留学生、QS前100、QS前200、QS前50（高端场合用）
- **届数标签**: 26-28届、26-30届（支持汉字写法：二六届、二八届）
- **学历标签**: 一年制英硕、美研在读、商科、计算机、文科、港硕、转码
- **学校举例**: 港大、NUS、UCL等QS前100高校、英国G5、常春藤
- **受众**: 留学生家长、家长（对家长说话时，留学生=孩子）

## 二、正面红利词

- **通道类**: 绿色通道、专属通道、独立招聘通道、快速通道、定向名额、海归专项
- **结果类**: 金饭碗、铁饭碗、稳进、上岸、稳拿、直接落户、降维打击、赛道碾压、直通终面、优先录取、送offer、网申通过率XX%
- **待遇类**: 免笔试、事业编制、安家费、住房补贴、人才补助、起薪XXw+、年薪XX万、一次性安家费、带薪年假XX天、18薪、期权激励、全球涨薪、全球化晋升、年假一上来就XX天起、准点下班是常态
- **动作类**: 捡漏、优先抓住、重点关注、盯住、精准匹配、直推
- **信号类**: 重新定调、上面表态、明确表态、释放信号

## 三、负面焦虑词

- **认知类**: 蒙在鼓里、不知道、寥寥无几
- **后果类**: 白交了、白花了、卡审核、卡死、栽了跟头、错过窗口期、白跑一趟
- **竞争类**: 卷成麻花、死磕、已读不回、当分母、人挤人、海投被已读不回
- **警告类**: 太可惜了、别高兴太早、颠覆你的认知、醒醒吧
- **低效类**: 盲目乱找、海投被已读不回、盲目海投、走偏了、独木桥、大傻子（慎用，攻击性极强）

## 四、装逼高端词

每版必用 2-3 个，制造精英信息差的居高临下感。

- **圈层标签**: 顶配 / 天花板 / 稀缺硬通货 / 精英赛道 / 顶流 / 头部梯队
- **姿态词**: 降维打击 / 赛道碾压 / 不在一个层级 / 直接甩开 / 锁定 / 卡位
- **信息差**: 真正懂行的家长 / 内行才知道 / 普通人根本不知道 / 99%的家长还在蒙在鼓里
- **阶级感**: 起点高度 / 圈层 / 人脉 / 阶级跃迁 / 人生杠杆 / 体面
- **稀缺感**: 仅限海归 / 独家渠道 / 不对外公开 / 只有留学生能走 / 名额有限 / 稀缺席位 / 稀缺人才
- **硬通货隐喻**: 硬通货（履历像硬通货一样值钱）/ 硬性刚需（不是加分是必须）/ 天生一对（留学生和国际组织的天然匹配）
- **系统级背书**: 国家人才库 / 自动匹配 / 黄金时间（投递窗口最优解）/ 补录（第二次机会的专业说法）
- **结果炫耀**: 别人还在苦等，你家已经稳了 / 别人家孩子海投石沉大海 / 普通应届生挤破头也进不去

## 五、与国内学生区分词

每版至少 2 处使用，强调海归不用跟国内生同台竞争。

- **动作区分**: 不用跟国内应届生挤 / 甩开统招竞争 / 绕开国内赛道 / 避开国内内卷 / 跳出普通校招池
- **身份对比**: 国内生还在XX，海归已经XX / 海归专属 vs 普通校招 / 留学生身份就是通行证
- **结果对比**: 别人在公海跟几千人抢，你在这个池子被点名要 / 国内生挤破头，海归走绿色通道
- **通道独占**: 只面向留学生 / 海归专项 / 不与国内生混招 / 国内生投不了 / 仅限海归准入 / 国内生连投递资格都没有 / 国内毕业生很难补齐这些短板

## 六、CTA 动词模板

- **引导词**: 敲 / 打 / 扣 / 留
- **扩展引导**: 留言（收集信息型，如"留言院校+专业"）/ 关注（涨粉型，如"关注悠悠老师"）/ 方括号数字（`敲[1]`/`[88]同步`——极简互动）
- **家长行动词**: 赶快帮孩子收藏、帮孩子存好、帮孩子盯住
- **交付词**: 发你 / 逐一发 / 同步一下 / 打包发你 / 立马发给您 / 悄悄我
- **替代**: 评论区告诉我 / 后台回复"XX"

## 七、圈层施压词

- **内行标签**: 真正懂行的家长 / 明白人 / 聪明的家长 / 懂行的
- **外行暗示**: 普通人 / 大多数家长 / 还不知道的 / 蒙在鼓里的
- **对比锚定**: "别人家孩子已经[X]了，你还在[Y]" / "你还在犹豫，别人家孩子已经拿到offer了"
- **占比压力**: 90%的家长 / 知道的寥寥无几 / 99%的留学生家长还在

## 八、留学生人设词

- **能力标签**: 双语能力 / 国际视野 / 跨文化沟通 / 英语流利 / 海外教育背景
- **身份优势**: 留学生独一无二的优势 / 留学生身份就是你的入场券 / 天然适配 / 完美适配
- **稀缺性**: 点名要留学生 / 仅限海归投递 / 留学背景优先 / 更认可海外院校 / 海归优先
- **反向打压**: "在HR眼里这只是标配"（先贬低再给出路，制造缺口后填补）
- **包容词**: 不管读的什么专业、不限专业门槛

## 九、机会鼓吹词

- **含金量**: 金饭碗 / 铁饭碗 / 含金量暴涨 / 真金白银 / 时代红利
- **降维**: 降维打击 / 赛道碾压 / 绕开90%的无效竞争 / 避开了无效内卷
- **确定性**: 稳进 / 上岸 / 稳拿 / 跳过笔试 / 直接面试 / 基本就稳了
- **待遇**: 起薪XXw+ / 年薪XX万 / 上四休三 / 18薪 / 不内卷 / 福利齐全 / 免税薪资 / 子女教育补贴 / 住房补助 / 全球医保 / 折合人民币XX万
- **对比**: "别人还在[苦逼状态]，你已经[爽感结果]" / "大厂996熬到脱发 vs 拿着高薪一周休三天"
- **外挂隐喻**: 复活币 / 开挂 / 外挂资源 / 容错率

## 十、招聘会专属词

- **活动名称**: 招聘会 / 双选会 / 人才对接会 / 高端人才活动 / 引才项目 / 线上双选会 / 空中双选会
- **活动特征**: 海归专场 / 海归招聘专区 / 留学生专属场次 / 捡漏专场
- **企业描述**: 头部大厂 / 行业龙头 / 知名外企 / 跨境制造企业 / 出海企业
- **岗位描述**: 对口岗位 / 定向岗位 / 专属通道 / 匹配度更高 / 总部岗 / 应届生专属岗 / 子弟调剂岗 / 国际业务 / 海外合规 / 涉外法务 / 境外投融资 / 管培生
- **单企业/组织**: 欧企（在华欧洲企业简称）/ 海外事业部 / 全球XX个国家和地区有岗
- **岗位代码体系**: Z开头=总部岗（神仙打架）/ S开头=应届生专属岗（绿色通道）/ L开头=子弟调剂岗——用于实操攻略类揭示信息差
- **参与动作**: 到场 / 参会 / 现场对接 / 当面沟通 / 跳过网申
