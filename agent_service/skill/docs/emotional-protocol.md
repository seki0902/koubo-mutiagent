# 口播稿情绪数值控制协议

## 一、情绪标尺定义

| 数值 | 情绪 | 留学生求职赛道含义 |
|---|---|---|
| -1.0 | 极度焦虑/恐惧 | 找不到工作、被淘汰、错过窗口期、学费白花了 |
| -0.5 | 轻微担忧/困惑 | 信息差、不知道政策、在无效竞争、蒙在鼓里 |
| 0.0 | 中性/陈述 | 事实描述、政策原文、活动通知、数据呈现 |
| +0.5 | 希望/轻松 | 有绿色通道、门槛降低、留学生专属、有解决方案 |
| +1.0 | 兴奋/确定/安全感 | 稳进编制、高额补贴、免笔试上岸、金饭碗 |

## 二、标准情绪曲线

| 稿件类型 | 曲线形状 | 数值走势 | 心理学原理 |
|---|---|---|---|
| **避坑警示类** | V型反转 | Hook(-0.8)→Trust(-0.3)→Solution(+0.7)→CTA(+0.5) | 先制造焦虑，再炫耀式救赎 |
| **红利揭秘类** | 阶梯上升 | Hook(-0.2)→Trust(+0.4)→Solution(+0.9)→CTA(+0.9) | 从好奇到兴奋，最后居高临下收尾 |
| **招聘会资讯类** | 脉冲式 | Hook(+0.4)→Info(+0.6)→Filter(+0.3)→CTA(+0.7) | 快速抓注意，秀专属门槛，促行动 |
| **权威背书类** | 正向权威 | Hook(+0.2)→Trust(+0.5)→Solution(+0.7)→CTA(+0.7) | 全程不制造焦虑，用"上面定调"建立信任，适合平台/渠道推介 |
| **单企业直招类** | 正向宣告 | Hook(+0.5)→Info(+0.6)→Solution(+0.8)→CTA(+0.7) | 纯正向起手（"重磅好消息""有福了"），用待遇数字拉兴奋，适合单企业/组织招聘通告（B2） |

## 三、分阶段执行指令

### Phase 1: Hook (0-3秒) | 目标情绪: -0.7 ~ -0.5 或 +0.4 或 +0.2 或 +0.5（正向宣告）

**任务**: 打破认知或制造紧迫，一句话建立"我知道你不知道"的信息差姿态。

**强制词汇**:
- V型/阶梯: "醒醒吧"、"大错特错"、"太可惜了"、"白交了"、"蒙在鼓里"、"真正懂行的家长早就……"
- 招聘会: "注意了"、"重磅来袭"、"快来捡漏"、"刚刚官宣"、"普通人根本不知道的……"
- 正向权威: "重新定调"、"上面明确表态"、"上面刚刚定音"、"重点保障"、"国家大力扶持"
- 正向宣告: "重磅好消息来了"、"有福了"、"机遇拉满"——纯正向爆炸式，不制造焦虑，直接宣告好消息（用于单企业直招 B2）
- 反转预期: "可能是最容易的一年了"——恐吓焦虑的反向用法，用"容易"制造稀缺感

**句式**: 强反问、否定句、时效提醒句、圈层施压句、正向宣告句
**禁止**: 温和的建议、平铺直叙（正向权威/正向宣告曲线除外——这两种曲线 Hook 不制造焦虑）

### Phase 2: Trust (3-10秒) | 目标情绪: -0.2 ~ 0.0 或 +0.5（正向权威）

**任务**: 建立可信度，展开说明。

**强制词汇**: "数据显示"、"上面刚刚定音"、"教育部举办"、"省教育厅牵头"、"HR内部透露"、"重新定调"、"精准匹配"
**句式**: 短句陈述、引用权威
**注意**: 保持冷静专业，为后面高潮做铺垫。语气要有"我在告诉你一个你查不到的东西"的感觉。正向权威曲线此阶段情绪偏高(+0.5)，用"不管读的什么专业""建议家长赶快收藏"等包容+行动句式维持信任感。

### Phase 3: Solution (10-35秒) | 目标情绪: +0.7 ~ +0.9

**任务**: 抛出红利/方案，展示确定性。必须出现与国内学生的对比。

**强制词汇**: "稳进"、"免笔试"、"降维打击"、"金饭碗"、"真金白银"、"专属通道"、"上岸"、"跳过网申"、"QS前XX优先"、"甩开国内统招"、"不用跟国内生挤"
**句式**: 排比句、数字锚定、对比句（海归 vs 国内生）
**注意**: 情绪饱满，语速加快，强调"容易"和"高回报"。必须至少 2 处区分国内学生，每处不超过一句半，嵌在信息里不成段。
**升级隐喻**: "铁饭碗变金饭碗"——双重好叠加，把情绪从 +0.7 推到 +0.9。先抛升级版结论，再展开原因。
**数字锚定**: 用精准数字替代模糊承诺——"18薪"比"待遇好"有力、"年假20天起"比"福利不错"有力、"折合33万"比"高薪"有力。搜索确认后使用，搜不到就用概括表述。

### Phase 4: CTA (35-50秒) | 目标情绪: +0.5 ~ +0.7

**任务**: 居高临下地给资源，降低行动门槛但不降姿态。

**强制词汇**: "全部打包好啦"、"逐一发"、"评论区扣"、"立马发给您"、"悠悠老师同步给您"、"有需要的家长啊"
**句式**: 祈使句、邀请句、施舍句（"有需要的……悠悠老师同步给您"）
**注意**: 保持精英感收官，像在分享一个"本来不想公开"的资源。不是朋友聊天，是专家施舍。用"扣"不用"敲"，用"同步给您"不用"发你"，CTA 尾句必须落在气口词上（啦/呀/啊）。

## 四、如何与 structure-templates.md 配合使用

1. 先选骨架（A1 / A2 / B / B2）
2. 再定情绪曲线
3. 每个段位同时参考骨架的"做什么"和本协议的"强制词汇+句式"
4. **初稿完成后，必须过 structure-templates.md 第七章「口播呼吸与节奏规范」做第二轮呼吸注入** — 情绪靠词汇，但节奏靠气口词和洋葱剥层。没有呼吸的情绪 = 喊口号；有呼吸的情绪 = 掏心窝子。

**示例 1**：写一篇招聘会稿
- 骨架 B：Hook → 信息 → 参与方式 → 紧迫 → CTA
- 情绪曲线：脉冲式
- Hook 段位 = 骨架 Hook + 情绪 Phase 1（招聘会词汇）→ 加气口词（啊/啦）
- 信息段位 = 骨架信息 + 情绪 Phase 2（权威陈述）→ 拆洋葱层（一句一信息点）
- 参与方式+紧迫 = 骨架参与+紧迫 + 情绪 Phase 3（红利词汇）→ 数字轰炸（数字间用句号）
- CTA = 骨架 CTA + 情绪 Phase 4 → 换临场词（扣/立马/同步给您）

**示例 2**：写一篇单企业直招稿（B2）
- 骨架 B2：Hook → 人群+待遇 → 岗位分布 → 优势强化 → CTA
- 情绪曲线：正向宣告
- Hook 段位 = 骨架 Hook + 情绪 Phase 1（正向宣告词汇，"重磅好消息""有福了"）
- 人群+待遇+岗位分布 = 骨架信息段 + 情绪 Phase 2-3（数字锚定待遇）
- 优势强化 = 骨架优势 + 情绪 Phase 3（区分国内生 + 升级隐喻 — 对比用绝对否定，不解释）
- CTA = 骨架 CTA + 情绪 Phase 4（施舍式：有需要的家长啊，扣XX，悠悠老师同步给您）
