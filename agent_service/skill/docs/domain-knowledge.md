# 留学生求职基础知识库

> ⚠️ 本文件不写进口播。仅供 AI 自检时核对事实，确保不胡说。

## 一、求职时间线

| 时间段 | 节点 | 说明 |
|---|---|---|
| 9月-12月 | 秋招 | 规模最大，海归+国内应届均可 |
| 3月-5月 | 春招 | 补录+捡漏为主 |
| 10月-12月 | 选调/国考 | 部分岗位海归可报 |
| 3月 | 省考 | — |
| 5月-6月 | 事业单位编 | — |

**一年制英硕典型节奏**: 9月入学同步投秋招 → 12月拿学位 → 完成学历认证后入职，或顺延至次年7月上岗。

## 二、基础概念

- **留服认证**: 教育部留学服务中心（中留服）出具的国外学历学位认证书。不是毕业证。回国求职/落户/考公必须办理。
- **人事档案**: 留学生回国后必须回户籍所在地人才服务中心建档。出国前状态不同（高中在读出国/高中毕业出国/本科后出国），所需材料不同。档案中没有留学经历=档案断档=考公落户被卡。
- **应届生身份**: 留学生毕业时间灵活，天然能跨两季校招。企业校招认定的毕业时间看学位证书上的**签发日期**，不是结课时间、论文提交时间或回国时间。
- **定向选调**: 各省面向部分高校（通常 QS 前100）单独招录，竞争远小于国考。
- **人才引进**: 各城市对海归人才的专项政策，通常含落户、住房补贴、生活补贴。每个城市政策不同，金额和条件以当地人社局最新公告为准。

## 三、事实搜索规则

以下信息在不同口播稿中可能不同，创作时**必须实时搜索确认**，不能编造：

- 招聘会/双选会的具体名称、时间、地点、报名方式和截止日期
- 在招企业名单、岗位方向和具体要求
- 政府官方求职平台名称和网址（如中国留学人才就业服务平台、中国公共招聘网等）
- 各地人才政策的具体名称、补贴金额和申请条件

**搜不到确切信息时**：用概括性表述代替具体数字或名称。例如不说"年薪 50 万"，说"高薪待遇"；不说某企业名，说"头部科技公司"。
